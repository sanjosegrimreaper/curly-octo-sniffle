## Verification methods

| Method               | Meaning                                                                                                                                                                              | Counts as confirmed |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------- |
| `http-200`           | The official page loaded (HTTP 200) and showed the fact.                                                                                                                             | yes                 |
| `browser-confirmed`  | A person checked the official page in a web browser (used for bot-protected sites).                                                                                                  | yes                 |
| `official-data-file` | Read from an official downloadable data file.                                                                                                                                        | yes                 |
| `official-pdf`       | Read from an official PDF document.                                                                                                                                                  | yes                 |
| `official-api`       | Read from an official data API (for example the data.medicaid.gov datastore).                                                                                                        | yes                 |
| `phone-confirmed`    | Confirmed by phone with the program or office.                                                                                                                                       | yes                 |
| `unconfirmed`        | Not yet confirmed on the official page (for example, seen only in a web-search result from the official domain). Allowed in draft packs only; the app labels it "Not yet confirmed". | no                  |
